> Note: This repository uses AI assistance to create the software kit since PixelWalker updates are too frequent for manual maintenance. Specifically, parsers for procedural macros and macro code generation is managed by AI.

This is a Rust library for interacting with the web game [PixelWalker](https://pixelwalker.net/) with a simple, opiniated and intuitive API.
